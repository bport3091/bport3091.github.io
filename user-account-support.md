# User Account Support — Learning Guide

**Type:** Conceptual learning guide. Update with screenshots only after completing an authorized lab.

## Common requests
- Password reset
- Account lockout
- New user access
- Access to a shared folder or application
- Account deactivation when an employee leaves

## Safe workflow
1. Verify the user's identity using the organization's approved process.
2. Clarify the exact system and error message.
3. Check whether there is a known outage or account status issue.
4. Use only approved tools and permissions.
5. Apply least privilege: grant only the access needed for the user's role.
6. Never ask for, record, or share a user's password.
7. Verify the user can access the resource and document the change.
8. Escalate requests requiring administrator approval or beyond your access.
