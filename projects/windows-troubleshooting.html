Windows Troubleshooting

A practical guide to investigating common Windows computer performance problems.

Scenario

A user reports that their computer has become slower than usual. This is a practice scenario, not a real customer incident.

Investigation Checklist

  1. Ask when the issue started and whether it affects one application or the entire computer.
  2. Open Task Manager by pressing Ctrl + Shift + Esc.
  3. Review CPU, memory, and disk usage.
  4. Check available storage in Windows Settings.
  5. Review startup applications and identify unnecessary items that can safely be disabled.
  6. Check whether Windows updates or a restart are pending.
  7. Make one appropriate change at a time and verify whether performance improves.

Good Support Practices

  • Get permission before making changes that could interrupt work.
  • Never disable security software as a shortcut.
  • Protect private information in screenshots.
  • Escalate issues that require additional access or expertise.
