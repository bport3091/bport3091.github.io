Windows Troubleshooting

A repeatable workflow for investigating a Windows computer that seems slower than usual.

Practice exercise

Scenario

A user says their computer has become slower than usual. This is a practice scenario, not a real support ticket.

Investigation checklist

  1. Ask when the issue started and whether it affects one application or the whole computer.
  2. Open Task Manager with Ctrl + Shift + Esc and review CPU, memory, and disk usage.
  3. Review available storage in Windows Settings.
  4. Review startup apps and identify only items that are safe and unnecessary to disable.
  5. Check whether Windows updates or a restart are pending.
  6. Make one appropriate change at a time, where safe, and compare performance afterward.

Good support habits

  • Get the user's permission before making changes that could interrupt work.
  • Do not disable security software or unknown services as a shortcut.
  • Protect private information in screenshots.
  • If symptoms suggest hardware failure, malware, or a critical outage, follow the organization's escalation process.
