Network Diagnostics

Learn to investigate common network connection problems using Windows tools.

Project Goal

Practice identifying possible causes when a computer cannot access a website or network resource.

Useful Windows Commands

ipconfig — View IP configuration.

ipconfig /all — View detailed network settings.

ping — Test connectivity to a destination.

tracert — Examine the route to a destination.

nslookup — Investigate DNS name resolution.

Troubleshooting Steps

  1. Check whether Wi-Fi or Ethernet is connected.
  2. Run ipconfig /all and review the IP address, gateway, and DNS settings.
  3. Test connectivity to the default gateway where appropriate.
  4. Check whether the problem affects one website or several.
  5. Use nslookup to investigate DNS resolution.
  6. Record your findings and identify the next troubleshooting step.
