# Brian Portilla — IT Help Desk Portfolio

A simple, responsive portfolio website for entry-level IT Help Desk / Technical Support applications.

## Contents
- `index.html` — portfolio home page
- `projects/` — project guides and sample ticket documentation

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `YOUR-USERNAME.github.io` (replace with your actual GitHub username).
2. Upload all files and folders from this package. Keep `index.html` at the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment to finish. Your site will usually be available at `https://YOUR-USERNAME.github.io/`.

You can also create a regular repository and enable Pages in Settings → Pages; the URL will include the repository name.

## Before publishing
- Replace the email and LinkedIn placeholders in `index.html`.
- Add your resume only if you are comfortable making it public; remove home address and other sensitive details first.
- Update the skills list based on what you can confidently discuss.
- Add screenshots and findings after completing each project. Do not present practice scenarios as real work experience.
- Review every project guide and personalize it with your own commands, screenshots, results, and lessons learned.
