# Sample Help Desk Tickets

**Type:** Simulations for portfolio practice. These are not real customer incidents.

## HD-001 — Wi-Fi unavailable
- **Reported issue:** User cannot connect to the office Wi-Fi.
- **Impact / urgency:** Determine whether one user or many users are affected and whether work is blocked.
- **Checks:** Confirm Wi-Fi is enabled, verify the correct network, check connection status and IP configuration, and compare with another approved device if available.
- **Example resolution:** In this illustrative scenario, Wi-Fi was disabled. Enabling it restored the connection.
- **Verification:** Confirm access to approved work resources.
- **Status:** Example only — resolved in the scenario.

## HD-002 — Cannot sign in
- **Reported issue:** User cannot sign in to their account.
- **Checks:** Confirm the exact error, verify keyboard layout and account name, check service status if available, and follow identity-verification and account-recovery procedures.
- **Security note:** Never ask the user to send their password. Do not bypass identity checks.
- **Next step:** Use approved password-reset process or escalate to the identity administrator.
- **Status:** Example only — requires investigation.

## HD-003 — Printer not responding
- **Reported issue:** User's print job does not print.
- **Checks:** Confirm the correct printer, check power and error indicators, review queue status, and determine whether other users are affected.
- **Next step:** Follow approved queue/driver procedures or escalate to the printer support team.
- **Status:** Example only — requires investigation.

## HD-004 — Computer running slowly
- **Reported issue:** User reports poor performance.
- **Checks:** Ask when it began, review Task Manager and storage, check pending updates, and determine whether the issue affects one app or the whole device.
- **Next step:** Make safe, approved changes and verify the outcome.
- **Status:** Example only — requires investigation.

## HD-005 — Suspicious email
- **Reported issue:** User receives an email requesting account credentials or an urgent payment.
- **Checks:** Ask whether the user clicked a link, opened an attachment, or entered credentials. Do not forward the message casually.
- **Next step:** Follow company incident-reporting procedures, preserve relevant details, and contact the designated security team promptly.
- **Security note:** Do not delete evidence or attempt to investigate beyond your authorization.
- **Status:** Example only — escalate according to policy.
